## III. Quy Chuẩn Kỹ Thuật

- **Độ phân giải**: `1284 × 2778 px` (Tương thích chuẩn App Store 6.5", 6.7" Super Retina Display và Play Store chuẩn HD/QHD).
- **Typography**: Font Nunito (Medium, Bold, ExtraBold) hỗ trợ trọn vẹn tiếng Việt có dấu.
- **Tỉ lệ tương phản (Contrast)**: Tuân thủ WCAG AA (≥ 4.8:1 đối với mọi chữ hiển thị trên nền gradient).
- **Mockup Frame**: Khung viền Titanium tối màu, bo góc chuẩn R=64px, Dynamic Island và hiệu ứng đổ bóng đa lớp (Gaussian Blur = 50px).
